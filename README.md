# sk-hynix

AI 코딩 에이전트(Codex)와 과제를 수행할 때 쓰는 **개인 작업 지침과 빈 문서 템플릿**입니다.
특정 과제의 풀이·코드·답안은 포함하지 않습니다.

## 구성
- `AGENTS.md` — 에이전트 작업 원칙 (MVP 우선, 단계별 검증, 결정 기록, 설명 방식, 금지 사항)
- `templates/PLAN.md` — 계획 문서 빈 양식
- `templates/WORKLOG.md` — 결정·검증 기록 빈 양식
- `templates/FINAL_CHECK.md` — 제출 전 점검표
- `setup.sh` — 위 파일을 작업 폴더로 복사

## 사용법 (작업 폴더에서)
```bash
git clone https://github.com/Chaewon-Park-STUDY/sk-hynix
bash sk-hynix/setup.sh
```
